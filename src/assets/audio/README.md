# Custom Audio Assets

Cocktail Merge synthesizes zero-latency crystal glass clinks, merge bells, and drop sounds using the Web Audio API.

If you prefer using your own recorded MP3/WAV audio files:
1. Place your audio files here:
   - `clink.mp3` — Played when cocktail glasses bump / clink into each other.
   - `drop.mp3` — Played when a cocktail is released from the dropper.
   - `merge.mp3` — Played when two identical cocktails merge.
2. The game will automatically detect and load `clink.mp3` on startup.
